**Статус:** поддерживаемая корневая точка маршрутизации

## Контракт индексации

1. Корневой `README.md` является человеческой точкой входа; `AGENTS.md` содержит только долговременные операционные правила для агентов.
2. `docs/README.md` регистрирует каждый поддерживаемый корневой документ и README каждого каталога первого уровня.
3. Подробная функциональность остаётся у локального владельца. Корневые документы не копируют списки требований и чек-листы.
4. Новая документальная директория получает собственный `README.md`, когда в ней появляется самостоятельная область или как минимум два связанных документа. Одиночный документ регистрируется у ближайшего существующего индекса.
5. В каждом документе должно быть понятно, описывает ли он текущее, целевое, временное или историческое состояние.
6. Перемещение или удаление выполняется после проверки входящих ссылок, runtime-потребителей, манифестов и владельцев долговременных правил.
7. После изменения документации запускается `npm.cmd run check` из корня. Автоматическая проверка подтверждает структуру и ссылки, но не заменяет смысловую проверку.
