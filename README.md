# S.Center workspace

**Статус:** рабочая область frontend-прототипа  
**Зрелость:** prototype; производственный backend, долговременное хранение, роли, права и эксплуатационные гарантии не реализованы

## Назначение

Workspace объединяет прототип S.Center, используемый им снимок общей компонентной базы и исходный переносимый снимок цифровой шахматки. Корень является точкой входа для людей и агентов; подробные продуктовые правила остаются у документов соответствующих функциональных областей.

## Состав

| Каталог | Текущая роль | Основная точка входа |
|---|---|---|
| `s-center-prototype/` | Активный браузерный прототип S.Center | [README прототипа](./s-center-prototype/README.md) |
| `component-library-transfer/` | Переносимый снимок компонентной базы, который прототип использует как внешнюю frontend-зависимость | [README компонентной базы](./component-library-transfer/README.md) |
| `digital-chessboard-transfer/` | Автономный исходный снимок шахматки и источник контракта переноса; не является runtime-зависимостью прототипа | [README снимка шахматки](./digital-chessboard-transfer/README.md) |
| `docs/` | Общая архитектура, владельцы спецификаций и маршруты контекста | [Индекс документации](./docs/README.md) |
| `scripts/` | Общие проверки структуры workspace | `npm.cmd run check` |

Правила работы агентов находятся в [AGENTS.md](./AGENTS.md). Границы каталогов и жизненный цикл transfer-снимков закреплены в [архитектуре workspace](./docs/workspace-architecture.md).

## Запуск прототипа

```powershell
cd s-center-prototype
npm.cmd run open
```

После запуска прототип доступен по адресу `http://localhost:4185/`.

## Проверка workspace

Из корня:

```powershell
npm.cmd run check
```

Команда проверяет:

- JavaScript и документацию `s-center-prototype`;
- JavaScript переносимого снимка шахматки;
- переносимость компонентной базы;
- локальные Markdown-ссылки и отсутствие машинных путей во всём workspace;
- регистрацию корневых документов и пакетов;
- действующий контракт побайтного совпадения runtime-копий шахматки.

Только общая документационная проверка:

```powershell
npm.cmd run check:docs
```

Сборка Storybook не входит в корневую проверку, поскольку требует предварительной установки зависимостей в `component-library-transfer`.
