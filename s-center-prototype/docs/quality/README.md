# Индекс проверок качества интерфейса

**Статус:** поддерживаемый локальный маршрут QA и historical evidence  
**Зрелость:** проверки frontend-прототипа; не production-гарантии  
**Родительский индекс:** [документация прототипа](../README.md)  
**Обновлять:** при добавлении, замене или утрате актуальности QA-checkpoint

Документы этой области подтверждают состояние прототипа на момент проверки. Они не создают новые продуктовые требования и не заменяют функциональную спецификацию.

## Правило обновления

- При изменении общей компонентной границы обновляется компонентный аудит.
- При повторении полного аудита шахматки текущая контрольная точка и её evidence заменяются актуальным компактным результатом; append-only журнал запусков не ведётся.
- При изменении проверенного состояния drawer прежняя QA-запись заменяется актуальным компактным результатом или получает явный исторический статус.
- Новые визуальные доказательства, необходимые для повторной проверки, сохраняются внутри проекта и связываются относительными ссылками; временные сессионные пути в поддерживаемую документацию не переносятся.
- Продуктовые решения маршрутизируются через [индекс цифровой шахматки](../digital-chessboard/README.md), а не выводятся из старых скриншотов.
