# Design QA: Chessboard и Bulk Action Bar

## Источники

- Шахматка: `design-qa-assets/source-current-prototype-matrix.png` — текущая runtime-реализация S.Center, открытая через Vite. MagicPath не использовался как визуальный источник.
- Панель действий: `design-qa-assets/source-bulk-action-bar.png` — приложенный пользователем референс.
- Реализация шахматки: `design-qa-assets/implementation-storybook-chessboard.png`.
- Сопоставление шахматки: `design-qa-assets/matrix-comparison.png`.

## Состояние и viewport

- Browser QA: Codex in-app browser, CSS viewport `2560 × 1440`, zoom/device ratio `0.625`; сохранённые полные снимки имеют размер `5120 × 2880`.
- Шахматка: пять этажей, шесть секций, все четыре состояния, disabled-ячейка, легенда.
- Панель одиночного выбора: счётчик скрыт, повторный клик по ячейке закрывает панель.
- Панель множественного выбора: начальное значение `3`, после добавления ячейки `4`, сброс очищает выбор и закрывает панель.

## Интерактивная и accessibility-проверка

- Arrow-клавиши переводят фокус между соседними доступными ячейками; проверено перемещение с `16 / Секция 1` на `16 / Секция 2`.
- Одиночный выбор: `hidden → visible → hidden` после двух кликов по одной ячейке.
- Множественный выбор: счётчик `3 → 4`, затем панель закрывается после сброса.
- Storybook Accessibility: `Chessboard — 0 violations, 24 passes`; `Bulk Action Bar — 0 violations, 15 passes`.
- Исправлены найденные в первой итерации нарушения: `toolbar` перенесён с недопустимого `aside` на `div`; контраст бейджа и служебного story-текста повышен до WCAG AA.
- В консоли компонентов ошибок нет; остаётся только собственное предупреждение Storybook 10 о будущем обязательном `ariaLabel` у `PopoverProvider` в Storybook 11.
